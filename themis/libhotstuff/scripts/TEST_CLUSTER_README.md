# HotStuff 集群测试脚本使用说明

## 概述

这是一个基于 `run_demo.sh` 和 `run_demo_client.sh` 开发的自动化测试脚本，可以一键启动多个 HotStuff 节点并进行压力测试。

## 脚本位置

```
libhotstuff/scripts/test_cluster.sh
```

## 使用方法

### 基本使用

```bash
# 进入脚本目录
cd libhotstuff/scripts

# 使用默认参数（4个节点，1000次迭代，100并发）
./test_cluster.sh

# 指定自定义参数
./test_cluster.sh 节点数 迭代次数 并发数
./test_cluster.sh 6 2000 150
```

### 参数说明

```bash
./test_cluster.sh [节点数] [迭代次数] [最大并发数]

参数：
  节点数      - 要启动的节点数量（默认4）
  迭代次数    - 测试的命令迭代次数（默认1000）
  最大并发数  - 客户端最大并发请求数（默认100）
```

## 功能特性

### 自动化流程
1. **依赖检查** - 验证可执行文件和配置文件
2. **节点启动** - 自动启动指定数量的 HotStuff 节点
3. **进程监控** - 实时检查节点运行状态
4. **压力测试** - 执行客户端压力测试
5. **自动清理** - 测试完成后自动清理进程

### 错误处理
- 自动检测端口占用
- 进程启动状态验证
- 优雅的错误提示和清理

## 故障排除

### 常见问题解决

1. **端口被占用**
   ```bash
   # 检查相关端口
   lsof -i :10000
   lsof -i :20000
   
   # 手动清理进程
   pkill -f hotstuff-app
   pkill -f hotstuff-client
   ```

2. **可执行文件缺失**
   ```bash
   cd ../..
   make
   ```

3. **配置文件不足**
   ```bash
   cd ..
   python3 gen_conf.py --prefix hotstuff --iter 4
   ```

4. **节点启动失败**
   ```bash
   # 查看具体节点日志
   tail -f logs/node0.log
   ```

## 性能调优建议

### 参数调整
- **小规模测试**：`./test_cluster.sh 4 100 10`
- **中等规模测试**：`./test_cluster.sh 4 1000 100`
- **大规模测试**：`./test_cluster.sh 4 5000 200`

### 系统资源配置
- 确保有足够的内存（建议4GB+）
- CPU核心数应大于等于节点数
- 网络带宽充足

## 开发参考

该脚本基于以下原始文件开发：
- `run_demo.sh` - 节点启动逻辑
- `run_demo_client.sh` - 客户端测试逻辑
- `hotstuff_app.cpp` - 节点应用程序
- `hotstuff_client.cpp` - 客户端应用程序
